# Angelo Nicolaci - Portfolio Developer

Benvenuti nel repository del mio portfolio personale. Questo progetto non è solo un curriculum online, ma una vetrina tecnica progettata per dimostrare il mio approccio all'architettura software, alla qualità del codice e alla risoluzione di problemi complessi.

🚀 **Sito Live: [https://darkfireangel.github.io/portfolio/](https://darkfireangel.github.io/portfolio/)**

## 🎯 Obiettivo del Progetto
L'obiettivo di questo portfolio è spostare l'attenzione dalla semplice lista di esperienze lavorative alla dimostrazione pratica delle competenze tramite **Case Studies** dettagliati. Ogni progetto è presentato analizzando il **Problema**, la **Soluzione** tecnica e i **Risultati** ottenuti.

## 🛠️ Stack Tecnologico
- **Framework**: Angular 18 (Standalone Components)
- **Styling**: SCSS avanzato per un design "Premium Dark" con accenti red-accent
- **Architettura**: Approccio component-based con focalizzazione sulle prestazioni
- **Deployment**: Pipeline di pubblicazione su GitHub Pages

## 📂 Flash sulle Competenze: AI & Legacy Modernization
Il progetto principale presentato in questo portfolio è la **AI Agents Pipeline**, un sistema multi-agente per la migrazione automatizzata da COBOL a Python che utilizza:
- **LangGraph** per l'orchestrazione degli agenti.
- **Mistral AI (mistral-small-latest)** per la generazione del codice.
- **Marimo** come interfaccia di runtime interattiva.
- **MLflow** per il tracciamento e l'ottimizzazione dei prompt.

## 👨‍💻 Filosofia di Lavoro
Il codice qui presentato riflette la mia ossessione per il **Clean Code** e la **precisione tecnica**:
- **Architettura & Design**: Priorità alla scalabilità e alla modularità.
- **Clean Code**: Codice ordinato, leggibile e facile da mantenere.
- **Debugging & Qualità**: Analisi verticale dei problemi, non solo di superficie.
- **Documentazione**: Ogni riga di codice è supportata da una logica strutturata.

## ⚙️ Sviluppo Locale
Se desideri esplorare il codice o avviare il progetto in locale:

1. **Clona il repository**:
   ```bash
   git clone https://github.com/DarkFireAngel/portfolio.git
   ```
2. **Installa le dipendenze**:
   ```bash
   npm install
   ```
3. **Avvia il server di sviluppo**:
   ```bash
   npm start
   ```
4. Apri il browser all'indirizzo `http://localhost:4200`.
